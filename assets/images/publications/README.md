# Publication previews

Images come from the archived versions of published papers, under CC BY 4.0.
The homepage credits the authors and links to the IEEE publications.

- `feeling-the-force.webp`: Khizar et al., robot photograph, https://arxiv.org/abs/2507.19831
- `localization.webp`: Dannaoui et al., evolving environment illustration, https://arxiv.org/abs/2507.17531

Images are resized and compressed for the web. Photographs fill their preview
frames; the annotated illustration is kept intact.
